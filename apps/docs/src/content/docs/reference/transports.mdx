The transports subpath exports the UI-facing transport surface.

## Exports

- `MessageTransport` (type) — `send(type, header, payload?)` + `subscribe(handler)`.
- `createWebSocketTransport(urlOrOptions?)` — same-origin default, cookie
  bootstrap, reconnect with backoff.
- `createMockTransport(handlers?)` — deterministic, in-process responses for
  tests.

## Options

`createWebSocketTransport` accepts a URL string or options:

- `url?` — default `ws://<location.host>`; browser dev passes
  `VITE_BARE_WS_URL` explicitly.
- `login?` — default `true`: bootstrap the `bare_session_<port>` cookie via
  `POST /login` when `window.__ekrooh.bootstrap` is present. The raw session
  token is never a login credential.
- `maxRetries?` — default 5.
- `backoffMs?` — default 250, doubling to a 2s cap.

The transport never places a credential in a URL — there is no `?token=`
fallback.

```ts
import { createWebSocketTransport } from '@ekrooh/bare/transports';

const transport = createWebSocketTransport();
```
