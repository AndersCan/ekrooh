title: iOS
description: The iOS host Swift package — BareHost.
---

The iOS host is a Swift package (`BareHost`) that ships as a **git-fetchable
package from the repo root `Package.swift`**, so consumers add it as a normal
SPM dependency at an exact ekrooh tag. The runtime binary (`BareKit.xcframework`)
is bundled as a `.binaryTarget` resolved through the same tag — no sibling
checkout, no cross-repo npm step.

## Public surface

- `BareProtocol` — Swift mirror of the binary wire protocol.
- `HostIpcCoordinator` — IPC frames; delegates host plugins.
- `HostPluginRegistry` — plugin ID → handler map.
- `BareHostLogger` — unified logger (`subsystem: "to.holepunch.bare.ios"`).

## Dependencies

- `BareKit` — vendored `Worklet`/`IPC` bridge (`Sources/BareKit` +
  `Sources/BareKitBridge`, from `holepunchto/bare-kit-swift`, Apache-2.0).
- `BareKit.xcframework` — the runtime binary, bundled as a SwiftPM
  `.binaryTarget` resolved from the release tag artifact. Vendoring the bridge
  (rather than depending on the upstream git package) is what lets it resolve
  `<BareKit/BareKit.h>` with no consumer `FRAMEWORK_SEARCH_PATHS`.
- P2P addons (udx-native, rocksdb-native, sodium-native, + hypercore's
  native deps) linked via `bare-link` and verified on the simulator.

## Consuming

```swift
.package(url: "https://github.com/AndersCan/ekrooh", exact: "X.Y.Z")
// targets:
.product(name: "BareHost", package: "ekrooh")
.product(name: "BareKit",  package: "ekrooh")
```

An app target must still embed `BareKit` and the `bare-link --preset ios`
addon frameworks into its `Embed Frameworks` phase. See `ios/readme.md` for
the full contract.

## Reference app

`examples/ios-app` runs the same web assets; the reference host wires a real
picker/camera (`PHPickerViewController` + `UIImagePickerController`) and real
permissions (`AVCaptureDevice.requestAccess`).

```bash
npm run prebuilds   # prebuilds/ios/BareKit.xcframework
npm run build:ios   # addons/, Resources/, ios-app.xcodeproj
npm run test:ios    # XCTest + UI test on the simulator
```

Tests: `Tests/BareHostTests/` (XCTest mirroring the JUnit suite) + a UI test
against the reference app.
