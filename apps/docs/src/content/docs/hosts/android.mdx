The Android host is a library module (`:bare-host`) published as a
**self-contained AAR** (`io.github.anderscan.ekrooh:bare-host` on **Maven Central**, with GitHub
Packages as a fallback): the Bare Kit runtime jar ships in the AAR's `libs/`
and its native libs in `jni/`, so consumers need no separate prebuilds
download.

The version tracks the framework version (single version across the npm package
and the AAR, released together on the same tag — see `RELEASING.md`). Pin it to
the framework version you depend on.

## Public surface

- `BareProtocol` — Kotlin mirror of the binary wire protocol.
- `HostIpcCoordinator` — frames in/out of the worklet's IPC.
- `HostPluginRegistry` — maps host plugin IDs to handlers.
- `BareWebViewClient` — WebView wiring; logs resource errors.

## Reference app

`examples/android-app` is the shell that embeds the backend and WebView:

- The shell starts the worklet with the web assets dir, reads `handoff.json`,
  injects `window.__ekrooh = { bootstrap }` (a one-time nonce, never the raw
  token; plus `window.BareShell`), and loads
  `http://127.0.0.1:<port>/index.html`.
- A real native photo picker/camera feeds `vendor.media`.

## Consuming

```gradle
repositories {
  mavenCentral() // default in modern Gradle/Android Studio; no auth needed
}

dependencies {
  implementation "io.github.anderscan.ekrooh:bare-host:<version>" // same version as @ekrooh/bare
}
```

> **Note**: the groupId is your verified Maven Central namespace with the
> project's sub-namespace appended (`io.github.anderscan.ekrooh` — parent
> `io.github.anderscan` is the reverse of the GitHub Pages URL and
> auto-verifiable via your GitHub account). If you were consuming from GitHub
> Packages before, the maven layout is identical — just drop the `maven { url =
"https://maven.pkg.github.com/AndersCan/ekrooh" }` repository and the
> `read:packages` PAT wiring. No credential block is required for Maven
> Central.

```bash
npm run prebuilds      # fetch Bare Kit prebuilds (prebuilds/)
./gradlew :examples:android-app:assembleDebug
```

The Gradle `Exec` tasks that build the JS inputs assume a **flat node_modules**
(npm/yarn, or pnpm with `nodeLinker=hoisted`) and run from the repo root — see
[Android Host Build](../consumers/android-host-build) before copying the
`build.gradle` pattern into a consumer repo.

Tests: JUnit in `src/test/` (`./gradlew :bare-host:testDebugUnitTest`).
