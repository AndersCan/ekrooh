---
title: Dev Mode & Storage
description: Run a stateful consumer backend under the bare CLI.
---

Under the `bare` CLI, `resolveWorkletConfig()` returns `{}`: no storage dir, so
`deviceMode` is off, auth is off, and the port is fixed at `8080`. For a
**stateful** consumer app (photos persisted across restarts) you need storage:

```ts
import { createWorkletRuntime, resolveCliConfig } from '@ekrooh/bare/runtime';

const config = resolveCliConfig(); // parses labeled bare CLI tokens (dev mode)
const runtime = createWorkletRuntime(config);
```

`resolveCliConfig()` parses `key=value` tokens from the bare CLI argv and
returns a dev-mode `WorkletRuntimeOptions` — auth off, fixed port 8080, no
handoff — without flipping device mode on. That's the CLI equivalent of the
hand-rolled options object:

```ts
const runtime = createWorkletRuntime({
  storage: './.justus-store', // durable app-sandbox dir
  cache: './.justus-cache', // ephemeral
  auth: false, // dev backend has no token
  port: 8080,
});
```

What you get and what to watch for:

- `deviceMode` defaults to `options.storage !== undefined` — passing `storage`
  flips you into device mode (auth on, ephemeral port). Override it with an
  explicit `deviceMode: false` to keep dev semantics with a storage dir;
  `resolveCliConfig()` does exactly that.
- With `auth: false`, **no `handoff.json` is written** even though `storage`
  is set — the handoff file is a host artifact, and a dev backend must not
  leave a stale one behind.
- The canonical default plugin set is registered automatically. Add **your
  own** plugins with the `plugins` option instead of mutating the registry
  after creation:

```ts
const runtime = createWorkletRuntime({
  storage: './.justus-store',
  cache: './.justus-cache',
  auth: false,
  port: 8080,
  plugins: [photosPlugin], // your app.photos manifest
});
```

`pluginRegistry` remains reachable on the runtime if you need to register
dynamically.

## Persisted dev data

Anything your backend writes under `storage` (hyperdrive cores, photo
metadata) survives restarts because you passed a real directory. `cache` is
for spool/temp. The same dirs map 1:1 to the `[webAssets, storage, cache]`
Bare.argv triple the host passes on device — so dev and device stay
config-identical.
