---
title: Host Handoff Flow
description: How a consumer MainActivity boots the worklet and loads the page.
---

The loopback/cookie/handoff sequence is what a consumer host shell implements.
Both reference shells (`examples/android-app` and `examples/ios-app`) do it;
here is the exact flow.

## Sequence

1. The host starts the worklet with three sandbox dirs:
   `[<webAssets>, <storage>, <cache>]`. `webAssets` is your built web app;
   `storage` is durable (photos, p2p corestore); `cache` is ephemeral.
2. The worklet binds `127.0.0.1` on an **ephemeral** port and writes
   `handoff.json` (`{ origin, port, token, bootstrap }`) into `storage`.
3. The host polls for `handoff.json`. It keeps **`token`** for its own IPC
   needs and injects **only `bootstrap`** (the one-time nonce) into the page
   **before** any page script runs:

   ```js
   window.__ekrooh = { bootstrap: '<bootstrap>' };
   window.BareShell = true;
   ```

   Never inject the raw `token` into the page — page JS (third-party scripts, a
   consumer plugin dispatch handler) could read it and mint authorized requests
   to every other gated resource.

4. The host loads `http://127.0.0.1:<port>/index.html`.
5. The page's WebSocket transport reads `window.__ekrooh.bootstrap`, calls
   `POST /login` once (the nonce is single-use), gets the `bare_session`
   cookie, and connects to `ws://127.0.0.1:<port>` — same origin, so
   cookie-authenticated. The transport never places the credential in a URL.
6. Media URLs returned by plugins are same-origin too — `<img>`/`fetch` ride
   the cookie, no token in the URL.

## Android (reference)

`examples/android-app/src/main/java/to/holepunch/bare/android/MainActivity.kt`
shows the full wiring. Key bits: start the worklet with the asset dir, wait
for the handoff file, inject `window.__ekrooh = { bootstrap }` via
`addDocumentStartJavaScript`, then `loadUrl("http://127.0.0.1:<port>/index.html")`.

## iOS (reference)

`examples/ios-app/app/BareRuntime.swift` does the same with a `WKUserScript`
injected at `.atDocumentStart`.

## Security notes

- `handoff.json` must be written to the **host-provided** sandbox dir, never a
  shared location.
- The **page** receives only a one-time bootstrap nonce; the real token stays
  in `handoff.json` for the host only. The cookie is `HttpOnly; SameSite=Lax`.
- Non-browser clients use the `X-Bare-Token` header. There is no `?token=`
  URL fallback.
- All loopback responses send `Referrer-Policy: no-referrer`.
